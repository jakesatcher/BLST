BLST API

Base URL /api/v1. JSON in and out. CORS is open, so browser apps on other domains can call it.

Auth: reads are public. Writes need Authorization: Bearer <key>. x-api-key and x-admin-token are also accepted. Roles: admin can do everything, scorekeeper can run games, and readonly can use exports when PUBLIC_EXPORTS=false. Keys are created in Admin → API keys. People sign in to accounts instead (below) and use the returned session token the same way. GET /me shows the role of the current key or session.

Errors: {"error": "message"} with a 4xx status (400 validation, 401/403 auth, 404, 409 conflict/state, 422 import rejected).

Export API (for other applications)

GET/export/tournaments/:idEverything in one call: tournament, teams with rosters, standings, games, skater and goalie stats. Add ?format=csv to get skaters as CSV.
GET/export/tournaments/:id/skatersSkater lines (G, A, PTS, +/-, PIM, PPG, PPA, SHG, SHA, GWG, ENG, SOG, S%, hits, blocks, FOW/FOL, FO%, GV/TK…). ?format=csv
GET/export/tournaments/:id/goaliesGP, TOI, W/L/OTL/T, SA, GA, SV, SV%, GAA, SO. ?format=csv
GET/export/tournaments/:id/standingsStandings. ?format=csv
GET/export/tournaments/:id/gamesSchedule and results. ?format=csv
GET/export/games/:idFull game snapshot and play-by-play. ?format=csv gives the events.
GET/export/players/:idCareer: imported history, per-tournament lines, totals. ?format=csv
GET/export/playersAll players (no emails). ?format=csv

JSON exports include schema_version (currently 1) and exported_at. Player stat lines include by_team splits for players who moved teams mid-tournament.

{ "type": "goal", "player_id": 41, "assist1_id": 44, "clock": "12:34" }

Event type: goal, shot, missed_shot, blocked_shot, penalty, faceoff, hit, giveaway, takeaway, goalie_change, penalty_shot, shootout_attempt, timeout, note. If you leave them out, BLST fills in: period and time from the clock (or pass clock as mm:ss remaining, or elapsed_sec); team from the player's lineup; goalie as whoever is in net; empty_net; strength (from penalties); and penalty_minutes from penalty_severity (minor, double_minor, major, misconduct, game_misconduct, match, bench_minor). Other fields: secondary_player_id (loser, player hit, shooter who was blocked, player who drew the penalty), infraction, coincidental, result (goal/save/miss), on_ice_home/on_ice_away (for +/-), notes.

Webhooks

BLST POSTs to each subscribed URL: {"id": 81, "event": "game.final", "created_at": "…", "data": {…}}. A failed delivery is retried twice (after 5s and 30s). Delivery history is in Admin → Webhooks.

Events: game.created, game.started, game.clock, game.period, game.event.created|updated|voided|restored, game.final, game.reopened, game.deleted, roster.added|updated|removed|moved|imported, player.created|updated, team.updated, tournament.created|updated|deleted, schedule.generated. Subscribe with *, exact names, or prefixes like game.*.

Headers: X-BLST-Event, X-BLST-Delivery, X-BLST-Timestamp, X-BLST-Signature: sha256=HMAC_SHA256(secret, timestamp + "." + rawBody).

const expected = "sha256=" + crypto.createHmac("sha256", SECRET)
  .update(req.headers["x-blst-timestamp"] + "." + rawBody).digest("hex");
if (!crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(req.headers["x-blst-signature"]))) reject();
